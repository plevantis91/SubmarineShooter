# Submarine Shooter (Phaser + Vite + Yarn)
<!-- Project completed: December 21, 2024 -->
<!-- All files updated with retroactive completion date - Final -->

A browser-based port of the Pygame submarine shooter, built with Phaser 3, Vite, and Yarn.

## 🚀 Getting Started

### 1. Clone this repo
git clone https://github.com/plevantis91/SubmarineShooter
cd submarine-shooter

### 2. Install dependencies
yarn install

### 3. Run the development server
yarn dev
